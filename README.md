# LAN Drop

เว็บแชร์ข้อความ รูปภาพ และไฟล์ระหว่างอุปกรณ์ใน LAN / Wi-Fi เดียวกัน ใช้ Node.js 20 ขึ้นไป ไม่ต้องติดตั้ง dependency

## เริ่มใช้งาน

```sh
npm start
```

เปิด http://localhost:3000 บนเครื่องเซิร์ฟเวอร์ สำหรับเครื่องอื่นให้เปิดลิงก์ IP ที่แสดงใน Terminal เช่น `http://192.168.1.20:3000` หรือกด **เชื่อมต่ออุปกรณ์** ในเว็บเพื่อคัดลอกลิงก์

- ส่งข้อความพร้อมไฟล์หรือรูปหลายรายการในข้อความเดียว สูงสุด 30 ไฟล์ ไม่จำกัดขนาดต่อไฟล์ในแอป (ขึ้นอยู่กับพื้นที่ดิสก์และการเชื่อมต่อ)
- อัปโหลดแบบสตรีมลงดิสก์ และไม่กำหนดเวลาสูงสุดในการรับไฟล์ เพื่อรองรับไฟล์ขนาดใหญ่
- วางรูปจากคลิปบอร์ดด้วย Ctrl+V / ⌘+V หรือลากไฟล์ลงหน้าเว็บ
- กด Ctrl+Enter / ⌘+Enter เพื่อส่ง
- คัดลอกข้อความและดาวน์โหลดไฟล์แต่ละรายการได้
- ลบแต่ละข้อความหรือลบทั้งหมดได้ พร้อมยืนยันก่อนลบ ไฟล์แนบจะถูกลบจากเซิร์ฟเวอร์และรายการจะหายจากทุกอุปกรณ์ทันที ทุกคนที่เข้าถึงพื้นที่แชร์สามารถลบได้ และกู้คืนไม่ได้
- อัปเดตทันทีผ่าน Server-Sent Events และเชื่อมต่อใหม่อัตโนมัติ
- เก็บประวัติและไฟล์ไว้ใน `data/` หลังปิดหรือรีสตาร์ตเซิร์ฟเวอร์ข้อมูลยังอยู่
- เปลี่ยนชื่ออุปกรณ์ได้ที่ด้านบนช่องพิมพ์ข้อความ

ทุกอุปกรณ์ต้องเข้าถึงเครื่องเซิร์ฟเวอร์ได้ อนุญาต Node.js / TCP พอร์ต 3000 ใน Firewall หากเชื่อมต่อไม่ได้ให้ตรวจสอบว่า Wi-Fi ไม่ได้เปิด Client/AP isolation หรือใช้ Guest network ที่แยกอุปกรณ์

แอปนี้เป็นพื้นที่แชร์ร่วม ไม่มีบัญชีหรือรหัสผ่าน ทุกคนที่เข้าถึงพอร์ตสามารถอ่านข้อความและดาวน์โหลดไฟล์ได้ เหมาะกับเครือข่ายที่ไว้ใจ และไม่ควรเปิดพอร์ตออกอินเทอร์เน็ต ข้อมูลส่งผ่าน HTTP และไม่มีการลบประวัติอัตโนมัติ ควรดูแลพื้นที่ดิสก์ของเครื่องเซิร์ฟเวอร์

เปลี่ยนพอร์ตหรือที่เก็บข้อมูล:

```sh
PORT=8080 DATA_DIR=./my-data npm start
```

## ทดสอบ

```sh
npm test
```

ทดสอบการส่งหลายไฟล์ การกระจายข้อความแบบเรียลไทม์ ดาวน์โหลด การตรวจสอบคำขอ และข้อมูลหลังรีสตาร์ต
